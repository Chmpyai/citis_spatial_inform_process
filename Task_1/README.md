# Задание 1 — Форматы и технологии облаков точек

## О задании

Подготовить доклад и презентацию по одной из тем, связанных с форматами пространственных данных, технологиями лазерного сканирования или применением облаков точек.

## Вариант

**Вариант 2.** Перечень предложенных тем приведён в файле [`task.txt`](task.txt).

Темы охватывают форматы LAS/LAZ, E57, COPC и Entwine Point Tiles, сравнение LAS/LAZ, E57 и PLY, принципы time-of-flight и phase-shift, а также наземное, воздушное, мобильное и твердотельное лазерное сканирование.

## Материалы и результат

- [`task.txt`](task.txt) — список тем для подготовки.
- Решение/презентация пока не добавлены.

## Цель

Разобраться в устройстве форматов и/или принципах получения данных 3D-сканирования, их возможностях, ограничениях и практических областях применения.
